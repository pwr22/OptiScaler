HOW IT WORKS:

┌──────────────────────────────────────────────────────────────────────────────┐
│ GAME WITH XESS FG → FSR3 FG FLOW:                                           │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  1. Game calls:                                                             │
│     xefgSwapChainTagFrameConstants(context, frameId, constants)             │
│                                                                              │
│  2. OptiScaler hook intercepts:                                             │
│     hk_xefgSwapChainTagFrameConstants() [XeFG_Hooks.cpp]                    │
│                                                                              │
│  3. Extract frame data:                                                     │
│     XeFG_Inputs_Dx12::TagFrameConstants() [XeFG_Inputs_Dx12.cpp]            │
│     - Camera: near, far, FOV                                                │
│     - Jitter: offset X, Y                                                   │
│     - Flags: depth inverted, jittered MVs, high-res MVs                     │
│                                                                              │
│  4. Convert format:                                                         │
│     xefg_swapchain_frame_constants_t → FG_Constants                         │
│                                                                              │
│  5. Send to ANY FG output:                                                  │
│     fgOutput->EvaluateState(device, fgConstants)                            │
│                                                                              │
│  6. FSR3 generates frames:                                                  │
│     FSRFG_Dx12 receives constants and generates frames                      │
│                                                                              │
│  Result: Game thinks it's using XeFG, but actually using FSR3! ✓            │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

CONFIGURATION:

In OptiScaler.ini:

  [FrameGen]
  FGInput=XeFG      ← Intercept game's XeFG API calls
  FGOutput=FSRFG    ← Redirect to FSR3 FG for frame generation

Supported combinations:
  • XeFG → FSRFG    (XeSS FG input → FSR3 FG output)
  • XeFG → XeFG     (XeSS FG input → XeSS FG output, passthrough)
  • XeFG → Nukems   (XeSS FG input → Nukem's FSR3-FG)
